# Portfólio · Guilherme F. Santos

Site estático em português para GitHub Pages, feito com HTML, CSS e JavaScript, sem etapa de build.

## Destaques

1. dashboard-banco-financeiro
2. dashboard-saas
3. Dashboard-Financeiro

Os textos e links foram preparados a partir dos READMEs públicos dos projetos. As imagens exibidas são capturas originais servidas pelos respectivos repositórios públicos. Os relatórios interativos abrem no Power BI. As imagens e os relatórios dependem da disponibilidade desses endereços externos.

## Publicação

No repositório `GU1LHO.github.io`, mantenha `index.html`, `styles.css`, `script.js`, `favicon.svg` e `.nojekyll` na raiz. Em Settings → Pages, selecione **Deploy from a branch**, branch **main**, pasta **/(root)** e salve.

URL esperada após uma publicação bem-sucedida: https://gu1lho.github.io/

## Atualizar

- Textos, contatos, links e ordem dos projetos: `index.html`.
- Cores, fontes e responsividade: `styles.css`.
- Ampliação das imagens: `script.js`.
- As cópias em `assets/` são uma referência local das capturas verificadas. A página usa as URLs públicas dos projetos.

Sem formulário, cookies de rastreamento ou dependências de JavaScript externas. As fontes são carregadas do Google Fonts, com fallback para as fontes locais do navegador. A navegação, os detalhes dos estudos e os links funcionam sem JavaScript; a ampliação das capturas requer JavaScript.
